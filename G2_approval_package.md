## 2. G2 method — tiered screening

### Tier 1: Coverage screening (all Phase 1 projects)

For each project:
- Verify project exists in archive (Google Drive / OneDrive)
- Record source availability: deliverables, briefs, correspondence, data
- Record evidence status: available / partial / missing / confidential
- Record lifecycle status: completed / ongoing / not awarded / unknown
- Record contracting role: prime / subcontractor / associate / unknown
- Record client acceptance: accepted / unconfirmed / rejected / unknown
- Assign preliminary spillover relevance: HIGH / MEDIUM / LOW / NOT_APPLICABLE
- Estimate evidence quality: RICH / MODERATE / THIN / NONE

**Output:** Coverage map showing which projects have evidence available and which are gaps.

### Tier 2: Targeted classification (projects with evidence)

For projects with MODERATE or RICH evidence:
- Apply v1.3 codebook claim classification
- Create atomic claims for spillover/option-relevant findings
- Record methods applied
- Record evidence links
- Create measurements for numeric claims
- Create validation actions for gaps

**Output:** Classified claims ledger entries for evidence-bearing projects.

### Tier 3: Prioritised deep evaluation (high-potential cases)

For projects with HIGH spillover relevance and RICH evidence:
- Full lens review (A and B)
- Counterfactual analysis where feasible
- Option value assessment
- Policy use verification
- Deep source reading

**Output:** Deep evaluation records for high-potential cases.

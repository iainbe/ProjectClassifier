# proposal_docs — mirror of Active proposals working documents

Versioned mirror of the `.md` working documents under `My Drive/Active proposals/`. The Drive folder is canonical; this directory exists so bid strategy documents, CAN question drafts, approach notes and decision documents are under version control alongside the toolkit.

**Rules:**
- Mirror `.md` files only — ITT packs, PDFs and spreadsheets stay Drive-only
- Folder structure mirrors `Active proposals/` exactly
- Update the mirror whenever a source doc is created or changed, in the same commit as the session's register changes
- If Drive and mirror diverge, Drive wins — re-copy the file

Established 26/10/08 with an initial sweep of all 23 existing working docs.
